Github Pages: https://vladislava05.github.io/mesto-production/
Как запустить проект:
# Клонировать репозиторий
git clone https://github.com/Vladislava05/mesto-production.git

# Установить зависимости (если используется сборка)
npm install

# Запустить локальный сервер (например, через Live Server или Vite)
npm run dev
